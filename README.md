## 🌟 Apa itu AiHana?

**AiHana** adalah aplikasi belajar untuk anak Sekolah Dasar yang dibuat supaya
belajar terasa **seru, hangat, dan tidak menakutkan**. Anak-anak ditemani dua
maskot lucu — **Pio si burung hantu 🦉** (malam hari) dan **Oyen si kucing 🐱**
(siang hari) — sambil memanfaatkan teknologi **kecerdasan buatan (AI)** sebagai
teman belajar yang sabar dan selalu siap membantu.

Seluruh aplikasi ada di dalam **satu file** `index.html` — tidak butuh server,
database, atau instalasi apa pun. Cukup dibuka di browser, langsung jalan. ✨

## ✨ Fitur Utama

| Fitur | Penjelasan |
|-------|-----------|
| 🦉 **Tanya Guru AI** | Anak bisa bertanya apa saja; AI menjawab dengan sabar, ramah, dan menyesuaikan tingkat kelas. |
| 🤖 **AI Anti-Putus (Rotasi Otomatis)** | Bisa dipakai **langsung tanpa API Key** (memakai AI gratis bawaan). Kalau punya API Key gratis, AiHana **berpindah otomatis** antar provider saat kuota harian habis — jadi belajar bisa seharian tanpa terhenti. |
| 📝 **Kuis Seru** | Soal pilihan ganda otomatis dari AI sesuai mata pelajaran & kelas, dengan animasi menyenangkan. |
| 📊 **Rapor & Monitoring** | Nilai kuis tersimpan, bisa dicetak jadi rapor rapi lengkap dengan predikat. |
| 📅 **Jadwal Belajar** | Atur jadwal pelajaran harian biar belajar lebih teratur. |
| 📚 **Referensi Belajar** | Kumpulan situs & video edukasi aman untuk anak SD. |
| 🔊 **Suara Maskot (TTS)** | Maskot bisa membaca teks dengan suara, ada pilihan preset suara yang mudah untuk anak. |
| 🌙 **Mode Gelap** | Tampilan malam yang lembut (soft night-blue), nyaman di mata. |
| 🎨 **Tema Pastel & Animasi** | Desain lembut dengan animasi halus yang bikin betah belajar. |
| 🏅 **Poin, Level & Lencana** | Kumpulkan poin dari kuis, naik level (Pemula → Master), buka 10 lencana seru. |
| 📲 **Bisa Di-install (PWA)** | Klik "Pasang Aplikasi" → ikon AiHana muncul di layar HP, bisa dibuka offline. |
| ✏️ **Atur Mapel & Referensi** | Guru/sekolah bisa menambah, mengubah, atau menghapus mapel & situs belajar sendiri. |

> 💡 Data anak (nama, nilai) **hanya tersimpan di perangkat masing-masing**
> (localStorage) — tidak dikirim ke mana-mana. Aman & privat.

## 🚀 Cara Memakai

### 1. Buka cepat (tanpa internet)
Klik dua kali `index.html` → langsung terbuka di browser (disarankan **Chrome**
atau **Microsoft Edge**).

### 2. Publikasi ke internet (jadi link yang bisa dibagikan)
Lihat panduan lengkap langkah-demi-langkah di **`PANDUAN-DEPLOY-VERCEL.md`**.
Ringkasnya: buat akun gratis di [vercel.com](https://vercel.com) → seret folder
ini → jadi link **`aihana.vercel.app`** untuk dibagikan ke teman-teman. 🎉

### 3. Mengaktifkan fitur AI
Fitur **Tanya Guru AI** & **Kuis** **langsung bisa dipakai tanpa API Key** —
AiHana punya AI gratis bawaan (Pollinations) sebagai jaring pengaman. Jadi anak
bisa langsung belajar walau belum paham soal API Key sama sekali. 🎉

Ingin lebih cepat/berkualitas? Isi satu atau lebih **API Key gratis** di menu
**⚙️ Setelan → Koneksi AI**. AiHana mendukung banyak provider **gratis
(tanpa kartu kredit)** dan akan **berpindah otomatis** ke provider berikutnya
saat kuota harian sebuah provider habis:

> **Provider gratis yang didukung:** Google Gemini · Groq · OpenRouter · Mistral ·
> SambaNova · Z.AI (GLM) · SiliconFlow · Scaleway · OVH · Cerebras · NVIDIA —
> plus **Pollinations** (tanpa key) sebagai cadangan terakhir.

**Tips penting:**
- 🔄 **Rotasi otomatis** aktif secara default. Makin banyak API Key gratis diisi,
  makin lama murid bisa belajar tanpa terputus.
- ✏️ **Nama model bisa diedit** per provider. Kalau suatu model dinonaktifkan
  penyedianya, tinggal ganti dengan nama model lain yang tersedia lalu **Simpan**.
- 🧩 **Mode Kustom AI** tersedia untuk menambah provider baru secara manual
  (isi Base URL + nama model + API Key sendiri).
- 🔑 **Contoh cara dapat API Key gratis (Google Gemini):** buka
  [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey) →
  *Create API Key* → salin → tempel di menu Setelan AiHana.

> Fitur lain (jadwal, rapor, referensi, lencana) tetap jalan tanpa API Key.

## 📲 Cara Memasang di HP (setelah online)
Setelah aplikasi dibuka lewat link (mis. `aihana.vercel.app`):
- **Android/Chrome:** ketuk tombol hijau **"⬇️ Pasang Aplikasi"**, atau menu ⋮ → *Instal aplikasi*.
- **iPhone/Safari:** ketuk tombol Bagikan ⬆️ → *Add to Home Screen*.

Ikon AiHana akan muncul di layar HP seperti aplikasi biasa, dan bisa dibuka
walau sedang offline. 🎉

## 📂 Isi Folder
```
aihana-deploy/
├── index.html            ← seluruh aplikasi AiHana (siap pakai)
├── manifest.webmanifest  ← identitas aplikasi (nama, ikon, warna) untuk PWA
├── sw.js                 ← service worker (bikin bisa dibuka offline)
├── icon-192.png          ← ikon aplikasi (kecil)
├── icon-512.png          ← ikon aplikasi (besar)
├── apple-touch.png       ← ikon untuk iPhone/iPad
├── vercel.json           ← pengaturan hosting untuk Vercel
└── README.md             ← file ini
```

> ⚠️ **Penting:** agar fitur "Pasang Aplikasi" & offline berfungsi, semua file di
> atas harus diunggah bersama (jangan hanya `index.html`). Fitur PWA hanya aktif
> saat dibuka lewat **https://** (link online), bukan saat file dibuka langsung.

## ❓ Pertanyaan Umum (FAQ)

**Apakah gratis?** Ya, sepenuhnya gratis.

**Apakah aman untuk anak?** Ya. Tanpa iklan, tanpa mengumpulkan data pribadi.

**Untuk kelas berapa?** Semua kelas SD (1–6). AI menyesuaikan tingkat kesulitan
dengan kelas yang diisi anak di profilnya.

**Perlu internet?** Untuk membuka lewat link & fitur AI: ya. Fitur kuis lokal,
jadwal, dan rapor tetap bisa dipakai offline (setelah halaman terbuka).

**Harus punya API Key untuk pakai AI?** Tidak wajib — AI gratis bawaan
(Pollinations) langsung jalan. API Key gratis hanya untuk hasil lebih
cepat/berkualitas dan tahan lama lewat rotasi otomatis.
