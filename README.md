# AiHana 🦉🐱 — Belajar Seru Bareng Pio & Oyen

Aplikasi belajar ceria untuk anak SD. Semua fitur (tanya-jawab AI, kuis, jadwal,
rapor, pengaturan suara) ada di dalam **satu file** `index.html` — tidak butuh
server, database, atau instalasi apa pun.

## ✨ Sejarah & Kisah di Balik AiHana

AiHana adalah karya seorang **siswi kelas 6A SDN Sindang Barang 3, Kota Bogor**.

Berawal dari rasa penasaran dan semangat mengikuti perkembangan **teknologi
kecerdasan buatan (AI)**, aplikasi ini lahir dari satu keinginan sederhana:
membuat belajar menjadi lebih seru, ramah, dan menyenangkan bagi semua teman.

AiHana tidak dibuat untuk satu orang saja — tapi **untuk semua teman agar bisa
belajar bersama**. Dengan memanfaatkan AI sebagai teman belajar, aplikasi ini
diharapkan bisa menjadi sarana yang menunjang siswa/siswi supaya lebih
**produktif, rajin, dan bersemangat** dalam menuntut ilmu. Ditemani dua maskot
lucu, **Pio si burung hantu 🦉 dan Oyen si kucing 🐱**, anak-anak diajak belajar
sambil tersenyum.

> "Semoga dengan AiHana, teman-teman semua jadi makin rajin belajar dan tidak
> takut lagi dengan teknologi — karena teknologi bisa jadi kawan belajar kita." ✨

## Isi folder ini
- `index.html` — seluruh aplikasi AiHana (siap pakai).
- `vercel.json` — pengaturan hosting untuk Vercel.
- `README.md` — file ini.

## Cara buka cepat (tanpa internet)
Klik dua kali `index.html` → langsung terbuka di browser (Chrome/Edge disarankan).

## Cara publikasi ke internet
Lihat panduan lengkap di file **PANDUAN-DEPLOY-VERCEL.md** (satu folder di atas),
atau ringkasnya: buat akun gratis di vercel.com → drag folder ini → jadi link
`aihana.vercel.app` yang bisa dibagikan ke teman-teman.
